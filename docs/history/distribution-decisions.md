# 配布の準備の経緯(M8)

配布物の仕様は [distribution.md](../dev/distribution.md)、手順は [release.md](../dev/release.md)。ここには、そこに至るまでの判断と調査の記録を残す。移行計画での位置づけは [migration-plan.md](migration-plan.md)(M8)。

## 1. 最初のリリースのビルドは arm64 だけだった(2026-10-11)

最初のリリースのビルドは arm64 だけで、Intel の Mac(macOS 15.8.1)で「このOSに対応していない」と表示された。Universal(arm64 + x86_64)に直した(`swift build --arch arm64 --arch x86_64`)。

最低の macOS は 14 とした(macOS 13 は対象外)。判断の経緯は [migration-plan.md](migration-plan.md)。Intel の Mac のうち、macOS 14 に更新できないもの(2017 年の MacBook Pro など)は対象外となる。この件を受けて、配布の前に、Intel の Mac で起動を確認する手順を加えた。

## 2. 署名の確認(2026-10-10)

ad-hoc 署名の Hardened Runtime で、画面の表示、ソケット、CLI が動くことを確認した。エンタイトルメントを付けない設計(WebKit のレンダリングは Apple の WebContent プロセスが行う。外部コマンドの実行、ソケット、ファイルの読み取りは Hardened Runtime でも制限されない)の根拠である。

## 3. 同梱物の検査(2026-10-10)

`strings` で、実行ファイルと同梱物に、個人のパスや秘密情報が残っていないかを調べた。

- 実行ファイルに、ビルドしたマシンのソースの絶対パス(`/Users/…`)が残っていた。release ビルドで、`-file-prefix-map` により `/hyperbuf` に置き換えるようにした(`make-app.sh`)。置き換え後は、残っていない。
- Web のバンドルとリソースに、個人のパス・秘密情報・ソースマップはない。Bundle ID(`com.yhojo.hyperbuf`)は、意図した公開の識別子。

## 4. 既定のアイコンの決定(2026-10-12)

既定のアイコンは「H」(暗い板の上に、半透明のタイルで「H」を描いたデザイン。Yasuo Hojo の作)に決めた。知り合いへの見せ合いで、「目立つ」「H が分かりやすい」という評価を得た。

代替のデザイン(分割した 2 つの window)は、視認性の評価が分かれたため、既定にしなかった。コードから生成できる形で、`app/macos/Resources/alternatives/` に残している。

元の画像は、暗い角丸の板が画像いっぱいに広がっていて、透明な余白がなかった。macOS のアイコンは、透明な余白がないと、Dock や Finder で他のアプリより大きく、角に四角い地が見える。そこで、元の画像から、角の外側は透明、周囲に約 10% の余白、影つきの、標準のアイコンを作る変換(`icon-from-image.swift`)を加えた。

## 5. v0.1.0 と v0.1.1

- **v0.1.0(2026-10-12):** 関係者への非公開の配布を開始した。Intel の Mac mini(macOS 15.8.1)で、起動と使用を確認した。初回のフィードバック 8 件に対応した。
- **v0.1.1(2026-10-14):** フィードバックへの対応をまとめた版。配布の `.dmg` に `CHANGELOG.md` を同梱し、利用者が更新内容を確認できるようにした。

## 6. 名称の商標の調査(2026-10-19、2026-10-23)

一般公開を見送る理由になった調査と、その後の登録状態の確認の記録。法的な助言ではなく、公開データベースの検索の結果である。

### 6.1 最初の調査(2026-10-19)

USPTO の商標検索(tmsearch)と TMview のあいまい検索で、次を確認した。

- 日本: 「HyperBuf」と同名の登録はない(関係がある名前は、Spansion の `HYPERBUS` だけ)。
- 米国: `HYPER-BUF`(第 9 類)。権利者は CA, Inc.(Broadcom)。
- ブラジル: `HYPERBUF`。権利者は CA, Inc.。

migration-plan の以前の調査(Web 検索だけ)は、これらを見つけられなかった。この結果を受けて、一般公開は行わず、希望者への限定的な配布にとどめることにした(経緯は [plan-change-log.md](plan-change-log.md))。この時点では、ブラジルの登録の内容と有効性が分かっていなかった。

### 6.2 登録状態の確認(2026-10-23)

公開を再検討するため、2 件の登録がいまも有効かを確認した。

|                  | 米国                                                                    | ブラジル                                                                 |
| ---------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 標章             | `HYPER-BUF`                                                             | `HYPERBUF`                                                               |
| 状態             | LIVE / REGISTERED                                                       | 登録済み                                                                 |
| 番号             | 出願 73750218、登録 1538027                                             | 出願・登録とも 818823720                                                 |
| 権利者           | CA, Inc.(Delaware 法人)                                                 | CA, Inc.(米国)。現地の代理人あり                                         |
| 区分・指定       | 第 9 類。ファイル処理能力を補助・向上させるコンピュータプログラム       | 国内分類 40:34。データ分析・処理サービス(役務。ソフトウェア商品ではない) |
| 出願 → 登録      | 1988-09-06 → 1989-05-09                                                 | 1995-10-02 → 1998-07-14                                                  |
| 更新・期限       | 2019-10-19 に更新(「Registered And Renewed」)。次の期限は 2029 年と推定 | 2010 年に更新。有効期限 2028-07-14                                       |
| 異議・取消・控訴 | 未確認                                                                  | 記録なし                                                                 |

- **確認の出典:** 米国の LIVE / REGISTERED、権利者、区分と商品は USPTO tmsearch で直接確認した。ブラジルは TMview(INPI のデータ)で確認した。米国の更新日と出願・登録日は、第三者サイト(Justia)の検索結果の要約によるもので、一次情報では確認できていない(USPTO の TSDR は 429 で開けず、Justia のページは Cloudflare の確認画面が出たため、迂回せずに中止した)。
- **ブラジルの 2018 年の手続き:** 公報に 2018-04-10 と 2018-07-03 の 2 件があるが、種別は「申立ての認容」と機械翻訳されるだけで、中身は確認できていない。
- **結論:** どちらも失効しておらず、名称をそのまま使って公開できる根拠は、現時点ではない。商品・役務は HyperBuf(Markdown ビューア)と同一ではないが、近い領域にある。混同の恐れがあるかは法的な判断であり、ここでは判断していない。
- **未確認:** 米国での使用の実態と、更新時に提出された使用の証拠。他国(EU、日本、中国など)の登録の有無(TMview の横断検索は未実施)。J-PlatPat の検索(簡易検索がビルトインのブラウザで動かなかった)。
- **次の候補:** TMview での他国の横断調査、弁理士への相談、公開する場合の改名の検討。方針はまだ決めていない。
