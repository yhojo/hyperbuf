## キー

- `C-f` / `C-b` — 参照履歴の Forward / Back(`Cmd+[` / `Cmd+]` も同じ)
- `C-n` / `C-p` — 1行スクロール、`C-v` / `M-v` — 1画面スクロール
- `TAB` / `S-TAB` でリンクを選び、`RET` でたどる
- `C-x 2` `C-x 3` `C-x 0` `C-x 1` `C-x o` — window の操作
- `C-x b` — buffer 切替、`C-x C-f` — ファイルを開く、`M-x` — コマンド実行
